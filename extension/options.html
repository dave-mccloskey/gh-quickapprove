Create a token

  1. Create a fine-grained personal access token ↗ with the name, description, 180-day expiration, and Pull requests permission prefilled.
  2. Select the repository owner, then choose All repositories.
  3. Confirm Pull requests is set to Read and write, generate the token, and paste it above. Your organization may require a shorter expiration.

GitHub requires you to select repository access on its form. All repositories covers the selected owner; it does not include repositories owned by other users or organizations.

Some organizations require approval or SSO authorization. Use a token for the same account you’re signed in to on GitHub.

A compatible classic token also works; private repositories require the broader repo scope. Prefer a fine-grained token when possible.

Your token stays in this Chrome profile and is sent only to GitHub’s API. Local storage is not an encrypted vault. Removing it here does not revoke it at GitHub; manage or revoke tokens there.
