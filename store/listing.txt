Name: GitHub Quick Approve
Summary: Approve a GitHub pull request with one click from its header.
Language: English (United States)
Suggested category: Developer Tools

GitHub Quick Approve adds a compact review button beside Submit review in GitHub's new pull request interface. Click once to submit an approval immediately.

The button distinguishes a PR that is ready for review from one you already approved. It also shows when a PR is merged, closed, your own, or unavailable for approval. Hover or focus the button for an explanation.

Connect your GitHub account with a personal access token in the extension's settings. The token stays in local storage in your Chrome profile and is sent only to GitHub's API. The extension does not synchronize tokens, run analytics, or use an external backend.

Works on github.com in the new pull request interface. GitHub Enterprise and the legacy PR interface are not supported. Clicking Quick approve submits immediately; it does not open a confirmation dialog or merge the PR.

This extension is an independent project and is not affiliated with GitHub.
